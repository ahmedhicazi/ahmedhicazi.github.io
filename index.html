04 — Journey

My learning journey

A continuous journey from programming fundamentals to building complete software applications and exploring modern development tools.

Programming Foundations

Started with C++

I started my programming journey with C++, learning programming fundamentals, writing functions and developing the logical thinking required to solve programming problems.

Problem Solving

Functional Programming & Problem Solving

I began applying programming fundamentals through functional programming and problem-solving exercises. This stage helped me learn how to break complex problems into smaller, structured solutions.

Object-Oriented Programming

Learning OOP with C++

I then moved into object-oriented programming with C++, learning how to design programs using classes and objects while working with concepts such as encapsulation, inheritance and polymorphism.

C# & .NET

Moving into C# and .NET

After building a foundation with C++, I moved to C# and the .NET ecosystem. I learned the C# language, its syntax and core concepts, then started building desktop applications using Windows Forms controls.

Databases

Learning SQL Server & Databases

I expanded my knowledge beyond application code and started learning relational databases and SQL Server, focusing on database fundamentals, data relationships and working with structured data.

Data Access

Connecting .NET with Databases

I learned how C# and .NET applications communicate with databases using ADO.NET, working with connections, commands, queries and data retrieval to build database-driven applications.

Real Project

Building a Complete Software System

I brought these skills together by building a complete software project using C#, .NET and SQL Server. The goal was to apply what I had learned in a real application and strengthen my understanding of how different parts of a software system work together.

Current Focus

Advanced C# / .NET & AI

I am currently deepening my knowledge of advanced C# and .NET concepts while learning how to use artificial intelligence and modern AI tools as part of the software development process. I continue to learn, experiment and build projects.
